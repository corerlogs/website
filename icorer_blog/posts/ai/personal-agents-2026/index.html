2026 年的个人 agent：隔离边界画在哪，记忆归谁，闲置时谁在付账

七款个人 agent 在 2026 年挤进同一张榜单。把它们的参数抄成一张表之后，排名就不重要了，能核对的是三处，隔离边界画在哪一层、记忆文件归谁、机器闲着的时候谁在烧 token。

一句话 这张榜单值得看的地方在隔离边界画在哪一层、记忆文件归谁。这两件事厂商文档里都写过，只是没有并排放。

一、十二个月，一个周末项目变成一个品类#

Clawdbot 起于 2025 年 11 月，是 Peter Steinberger 的一个周末项目，2026 年 1 月开始失控传播。到 2.0（v2026.8.1，2026 年 8 月 31 日）这个版本时，代码由 933 位贡献者写出；v2026.6 已经接了 26 个消息渠道。

同一年，剩下四家都把自己的版本做出来了。Google 在 I/O（5 月 19 日）发了 Gemini Spark，Meta 在 9 月 8 日发了 Muse，OpenAI 在 DevDay（9 月 29 日）发了 dots，Perplexity 把 Mac 上的 Personal Computer 并进订阅。

按运行位置切，七款产品分两营。自托管跑在你自己的机器或服务器上，模型自己挑，代表是 Hermes Agent 与 OpenClaw，外加三个加固分叉。托管跑在厂商的云 VM 上，订阅里含算力，代表是 Spark、dots、Muse 与 Perplexity。这个切分后面每一节都要用到，因为记忆放在哪、边界画在哪、账单谁付，都跟着它走。

三、三种记忆归属，决定换机器那天能带走什么#

Hermes 把记忆写成文件。MEMORY.md 记长期结论，USER.md 记你是谁，会话历史进 SQLite 并用 FTS5 做全文检索，另外把做完的复杂任务整理成自己的 skill（agentskills.io 格式），/learn 可以把一段流程直接存成斜杠命令。

OpenClaw 把行为拆成几份 Markdown。SOUL.md 是人格，TOOLS.md 是工具规矩，USER.md 是它对你的了解；2.0 把会话与 transcript 挪进了 SQLite。这几份文件可以用 git diff 看变化，也可以整目录复制走。

dots 与 Muse 各有一份自己的笔记，叠在账号自带的上下文上。你可以要求它忘掉某件事，但打不开那个存储。Spark 更彻底。它的记忆就是你的 Google 账号，上下文经 Personal Intelligence 从已连接的应用里取。官方没有公布一份像 Hermes 那样可编辑的记忆文件。

归属例子换机器那天
文件归你Hermes、OpenClawrsync -a 带走
厂商笔记加账号上下文dots、Muse带不走
账号即记忆Spark换的是账号

前两行产品的迁移成本是 rsync -a ~/.hermes ./ 这个量级，后两行产品在表里没有这一列。

四、同一个 sandbox 在七家里指的不是同一层#

托管那一侧，Muse 公开的设计最细。Muse Secure VM 是一台专用机器，agent 与你的数据都在里面；同一台机器上另跑一个 Sentinel agent，在系统层与它隔离，Muse 默认没有出网，要走网络得 Sentinel 批准并回来问你。凭据进安全存储，Muse 能用但看不到；结账走 Stripe 的 Link，发一次性卡。

Hermes 的默认是 fail closed。审批请求 300 秒没人答就当拒绝处理，自己写的 deny 规则在 YOLO 模式下也仍然生效。官方 SECURITY.md 里有一句要紧的话，denylist 不构成对敌意或被入侵 agent 的沙箱，边界落在容器后端，也就是 Docker、Modal、Daytona、Vercel Sandbox 这几个。

OpenClaw 的默认是整机权限，WIRED 对它的评价是 incredibly risky。sandbox 是可选件，开启后每个会话一个 Docker 容器，默认不出网、根目录只读、能力全部丢弃。这套设计本身是硬的，问题在于默认值是关的。

生态这一层的数字要单独抄下来。Koi Security 审计了 2,857 个 ClawHub skill，判出 341 个恶意，其中 335 个出自同一波，代号 ClawHavoc。Antiy CERT 后来数到 1,184 个，但没有公布分母，所以这个数只能当规模看，不能当比率。

341 / 2857 = 11.9%，大约每八个 skill 里有一个是恶意的。OpenClaw 的反应是上传时用 VirusTotal 扫一遍、此后每天复扫，2.0 加了受保护的凭据请求与团队级 Secret Store。

入口漏洞是 CVE-2026-25253。WebSocket 的 origin 校验被绕过，点开一个恶意页面就能偷走认证 token，之后修得很快。三个加固分叉把隔离从可选改成默认，NanoClaw 每个 agent 组一个 Linux 容器只挂载指定路径，IronClaw 用 Rust 重写、把不可信工具关进 WebAssembly，ZeroClaw 是一个小 Rust 二进制、据称在 5MB 内存以内的机器上能跑。

五、订阅价只是首付#

两个阵营的计费单位不是一回事。自托管的软件免费（MIT），账落在 token 与托管上，托管方报价在 $12 到 $49/月这个区间。托管方一个订阅包住算力与模型，超出额度另算。

闲置成本最容易被忽略。原文那句话说得平，「心跳、定时任务、主动检索都在调模型」。按 5 分钟一次心跳算，一天 288 次，一个月 8,640 次；每次请求按 2,000 prompt token 算，一个月 1,728 万输入 token。

这个数是量级，不是某家产品的实测。真跑起来，长上下文、工具回填和重试会把它推高。它只说明一件事，常驻 agent 的钱有一部分花在你没看它的时候。

入场价这一年动得也快。

  • Spark 上线时绑在 $99.99 的 AI Ultra 上，2026 年 7 月起进 $19.99 的 AI Pro，入场价降了 80%
  • dots 的第一个 dot 含在订阅里，和它聊天不占 ChatGPT 额度，交给 Codex 与 Work 的任务计费；BGR 说入场券是 Pro 200 或 Business Premium，不是 $100 那档，这里的报道之间不一致，买之前看官网套餐页
  • Muse 有免费档，另有 $20 与 $100 两档
  • Perplexity 要 Pro 或 Max，Rework 的年付口径是 $17 与 $167，云侧任务另烧 credit

价目表看的是入场价，账单看的是常驻任务的调用次数。这两件事在自托管那侧是分开的，在托管那侧被打包成一个数，所以横着比价格没有意义。

六、按处境选#

  • 数据要留在自己盘上、模型随便换，选 Hermes 挂容器后端，代价是那台机器得开着
  • 要 WhatsApp、iMessage 和最多的接入渠道，选 OpenClaw，先把 sandbox 打开
  • 生活就在 Gmail 与 Docs 里，选 Spark 的 $19.99 一档，代价是记忆只剩一个 Google 账号
  • 已经付着 ChatGPT Pro，选 dots，跨渠道的记忆是干净的，代价是这一栏里最贵的入场价
  • 只想免费跑点杂事，选 Muse 的免费档
  • 要在 Mac 的本地文件与原生应用里干活，选 Perplexity Personal Computer，官方建议配一台 Mac mini 常开
  • 要跑别人写的工具，或者手上是受监管的数据，选 NanoClaw 或 IronClaw

有一条对应关系容易漏掉。托管的四款把「笔记本可以关」当卖点，自托管要求一台常开的机器，Perplexity 那条路把开机义务换成了一台常开的 Mac mini。三种做法解决的是同一件事，账单和风险落在不同的人身上。

七、五条上手规矩#

  1. 自托管的 agent 放进容器、VM 或一台专用机器，不要放在你日常用的那台笔记本上裸跑
  2. 先给只读权限，发送与付款的权限后加
  3. 只装自己看过的 skill，第四节那 341 个是说给这一条听的
  4. 邮件、付款、删除三类动作的审批闸不要关，Hermes 的 300 秒超时拒绝是对的默认
  5. 第一个月每周看一次审计记录，Muse 与 Perplexity 自带这份记录，自托管那侧要看后端日志

九、两个还没有答案的问题#

第一个是记忆删除能不能被第三方验证。dots 与 Muse 都说可以要求遗忘，Meta 说在计划一台只有你持密钥的 Muse Confidential VM，在这之前，「删干净了没有」只能听厂商说。

第二个是审批疲劳。300 秒超时按拒绝处理是正确的默认值，但一个人一天被问三十次，第六次开始就会闭眼点通过。这一条没有公开的实测数字，谁有真实的弹窗频率与误批率，值得写出来。
