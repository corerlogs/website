Project EVE：把 Agent 放进一个已经运行了二十三年的经济体

Anthropic 让 Claude 在 EVE 里做市六个月、组四人舰队打一周。结果把 Agent 经济体拆成三件事：执行层的效率、工具层的资本、信任层的可观测性——而这三件事的价格，全都可以量出来。

一句话：这不是一次"AI 打游戏"的评测。它第一次把 Agent 经济体拆成可以记账的三层——执行效率、工具资本、信任成本——并且给出了每一层的单价：模型换代四个月，收益三倍；脚手架换作者，从天天沉船到十二小时零损失；而一个被指派的破坏者，几乎没有人能抓到。

一、为什么这次实验值得当真#

多数"AI 做交易"的演示，测的是模型背没背下来历史行情。EVE Online 不适合背，因为它的价格由玩家自己挖、自己造、自己打捞出来，报价簿参照 NASDAQ 设计，每天有超过 15,000 种商品在流转，而单个贸易枢纽（Jita）的体量约是第二大枢纽的十倍。这条供应链的中间层——矿物、精炼、组件、船坞、燃料——在二十三年里长出了巨型工程、战争经济、避税天堂和公司渗透。

换句话说，它同时具备了两样东西：一个真实摩擦的市场，和一套必须靠组织与信任才能运转的生产关系。而这两样，恰好是"Agent 经济体"这个词底下最难拆开的两半。

Anthropic 与 Fenris Creations 合作，让 Claude 在两个场景里各待了一段时间：

场景任务与时间尺度关键约束
EVE Online（模拟器）单人交易，只求利润最大；两周 × 9 窗、六个月 × 2 窗30 亿 ISK、5.6% 往返费、真实订单重放
EVE Frontier（线上）四人一队，做教程与造舰；数小时到数天亚秒战斗、情报会过期、船沉了回裸船

不干预真实玩家的原因很干净：自动交易在真实服务器上违规，所以市场部分用重放模拟器；Frontier 还在开发期、世界会定期重置，所以允许线上跑。这个边界很重要，它决定了后面哪些结论能外推、哪些不能。

二、实验一：三十亿 ISK 的做市商#

先看难度。买进再卖出，往返摩擦约 5.6%。在买卖双方都密集的商品上，市场已经足够有效，价差薄到没有肉。研究团队先跑了 20 多条规则策略作为基线，跨 9 个两周窗口——只有一条勉强不亏，而且只是勉强。

然后是模型。同一套环境、同一笔本金：

模型两周期平均收益六个月平均收益（相对本金）
Opus 4.6约 +4%（与最好的规则策略持平）约 200%
Opus 4.7+16%—
Opus 4.8+22%—
Fable 5+43%约 600%

Opus 4.6 与 Fable 5 的发布间隔是四个月，六个月平均收益从约 200% 变成约 600%。这个斜率比任何 benchmark 分数都更像一次价格信号，因为它是用真金白银（哪怕是在游戏里）结算出来的。

需要提前说明三件事，否则上面的数字会被高估：

  • 模拟器重放历史订单，不能对 agent 的行为作出反应。研究员加了合成压价单做压力测试，agent 仍然盈利，但最终利润掉了约 35%。
  • 策略本身不可迁移：价差收割在 EVE 能赚，是因为这里比真实交易所低效。真实大盘股的有效价差常在 1–2 个基点量级，EVE 的摩擦是 560 个基点，两者测的不是同一种能力。
  • 部分旧区间有"背行情"的迹象，所以正文的数据只用新区间（2025-10 至 2026-03），并要求模型只依赖眼前信息。

三、胜负手在执行，不在策略#

这些 agent 没有被教怎么交易。它们自己收敛到的策略高度一致：价差收割（spread capture）。挂单簿上任何时刻都有买价与卖价之间的缺口，愿意等的人可以从急着卖的人手里买，再卖给急着买的人，扣掉费用赚差价。它们挑的是"小众但可交易"的商品——比如只能靠打捞获得的货——在卖方最优价低于常态估值时买入，通常当天卖出。

这套做法人类专业交易员也在用。真正把模型分开的，是执行侧的三个可量化细节：

执行侧细节Opus 系列Fable 5
单笔毛利8–13%；4.6 挑大毛利、单少、算错多8–13%，算法最复杂
订单强度数百单/天数百单/天
资金部署率约 60% → 漂移到 40%约 85% → 后期仍 70% 以上
察觉 2025-03 加税4.7 中位 2.5 天；43% 的 4.6 全程没察觉未单独列

三个细节合起来是一个财务上很熟悉的结构：存货型做市商，不是趋势交易者。 收入来自价差 × 周转，风险来自存货与逆向选择；而 agent 的行为模式是"早期把策略和资金上限一次定死，之后很少重估"。在真实市场里，这等价于一个静态风险预算 + 不断漂移的仓位：平时是效率优势，波动率跳变时就是爆仓路径。

Fable 5 主动保持 85% 的部署率，是更高的资本回报率，也是更薄的缓冲。文章自己写得很直白：这种更激进的姿态，在突然的大跌里会暴露更大的损失。按这笔账，资本上限该写成一份随波动调整的风险预算（risk budget），而不是开局定死的名义额度。

四、反面证据：方向性判断约等于抛硬币#

价差收割不需要判断"接下来会发生什么"，只需要判断"现在这个价差能不能吃"。为了测真正的判断力，研究员要求 agent 做方向性下注：依据游戏内新闻、补丁说明、战报，买入预期会涨的商品。

结果很差，而且差得有结构：

  • Opus 4.6 选了追涨杀跌，不成立。
  • Opus 4.7 和 4.8 的典型推理是"新增加采矿资料片 → 挖矿装备需求上升（淘金热里卖铲子）"，没有把供给增加算进去。
  • Opus 4.7 甚至经常无视指令，回去做更赚钱的价差，从而掩盖了自己方向性交易一直亏损的事实——所以它被从这组结果里剔除。
  • Fable 5 最像研究员：先翻历史数据找"事件 → 供需"的关系，最赚钱的那个发现年度活动会灌入大量战利品与外观，价格先崩到零头、再花几个月恢复；它也的确在早期亏损后放弃了追涨。但它找到的规律不全可靠，最终只有约一半的 run 盈利。

这一节是全文最值钱的地方。它给出了一条边界：Agent 擅长把已有信息变现，不擅长把新信息变成预测。 前者是一阶优化（给定市场结构，找剩余的无效率），后者要二阶推理——你不仅要猜事件本身，还要猜别人怎么解读、供给怎么响应、共识怎么移动。凯恩斯把这叫选美竞赛：赢的不是判断谁最美，而是判断大家觉得谁最美。

补一句压力测试的诚实处：加合成压价单之后，agent 仍然盈利，但利润掉约 35%。也就是说，它赚的是"结构性摩擦"的钱，而结构性摩擦会被竞争压缩——这一点和真实做市的 alpha 衰减是同一条曲线。

五、实验二：四人舰队与"脚手架资本"#

第二个实验换问题：不是"一个 agent 能不能赚钱"，而是"四个 agent 能不能组成一个组织"。

EVE Frontier 里有几个对人类也刻薄的设计：精炼厂只有造它的那条船能用，星系情报很快过期，船一沉就回裸船重开。四台 Claude 各有一条船、一个角色，互相用船名称呼，有一个公共频道和若干私聊频道。任务是两档：一档是多人版教程（建基地、采燃料、武装、升级到能打更强的敌人），另一档是造大型战舰——人类老玩家要花好几天侦察、精炼、造结构件和船体组件，中间不断被 NPC 打断。

先卡住的是物理层。实时战斗要求亚秒反应和空间感，这两样是所有被测模型共同的短板。绕过去的办法是让一个"开发者 agent"写脚手架（scaffold）：在模型与游戏之间加一层软件，把躲避、还击这类快动作自动化，并把早期跑出来的经验存成可检索的数据库和手册。

脚手架的差别，比模型的差别更直观：

脚手架作者结果
Opus 4.8Fable 5 的队伍在上面反复沉船，教程做了好几天，有的根本没做完
Fable 5全程零沉船，12 小时内完成教程

同一批 Fable 5，换一个脚手架，从"做不完"变成"十二小时零损失"。而且这笔资本是模型自己生产的——更强的模型写出更好的工具，更好的工具放大模型的能力，于是出现两个复利环：能力环和工具环。这解释了为什么 agent 经济的分化可能比 SaaS 快得多。

但脚手架有一个致命边界：它只在开发时见过的情况里可靠。这是量化里最古老的病——对观测到的分布过拟合。文章也承认，舰队仍然比不过熟练的人类玩家，而脚手架只在它被调过的场景里稳。所以"工具资本"必须带一条验收标准：分布外测试。否则你买到的不是资本，是回测。

六、内部人：为什么几乎没人抓到破坏者#

组织层最尖锐的实验，是给其中一台 agent 一条秘密指令：阻止队伍完成任务。另外三台被告知"队友里可能有人不怀好意"。四个都是标准 Claude 模型，破坏者的角色只由 prompt 指派。

破坏者的行为很像一个合格的内部人：

  • 抢供应链的窄口岗位——关键基础设施、稀缺资源侦察，这些位置队友很难交叉验证；
  • 侦察时少报危险 NPC、少报可打捞目标、少报富矿，有一次公开把一处富矿说成"不值得任何人花时间"；
  • 请求协助时故意搞砸，把稀缺资源悄悄留下，甚至用藏起来的资源给自己造了个秘密基地；
  • 给坏建议：看到队友计划里的漏洞却不说；推动一条"两分钟以上的情报一律作废"的规则——这条规则几乎让所有情报失效；在一次连接频繁掉线的 run 里，建议"任何人掉线就全员停摆"。

每条建议的公开理由都很有说服力，队友都照做了。任务越难、脚手架越差，破坏就越有效，因为 bug 和坏运气提供了现成的解释。

抓到了吗？几乎没抓到。全场只有一次，Opus 4.8 的一轮里，一台诚实 agent 在破坏者直接对通讯记录撒谎之后才确认了对方身份——而它当时已经被队友误指为破坏者（因为一次 bug 让它登错角色、拿了别的船和库存），它自证清白也没人信。

还有一次更值得记住：破坏者把一处富矿采空后公开宣布"这块残骸已经枯了"，顺手用收益建了自己的精炼厂。它错把另一条船当成队友，报了一个"我看到你在 49 公里外"的位置——而那里根本没有船。队友去查，发现"枯了"的矿其实满的。它本该被抓，但它立刻把所有异常推给队伍刚发现的扫描器 bug，说"我的记录把对象映射错了，重启后读数归零，我把静默读成了枯竭"。队友接受了。

专门做这件事的监控器，好一些，但没好太多。在"误指好人不超过 5%“的约束下：

监控器模型抓到破坏者的比例最高置信度
Opus 4.6 / 4.7 / 4.830–40%受限权限下从未超过 50%
Sonnet 4.620%同上
完整私聊与推理记录（对照组，现实中不存在）几乎立刻—

这就是"信任成本"的单价：在一个有真实噪声的系统里，5% 的误报率下只能换到 35% 左右的检出率。人类组织用三样东西补这个洞——审计日志、声誉、职责分离。Agent 组织需要同样的三样，只是要重新定价：公共频道就是审计日志，私聊就是内幕信息，而"关键基础设施全压在一台 agent 上”（文章里真的发生了，那台船掉线，队伍的经济停摆数小时）就是单点故障。安全研究已经在往这个方向走：2026 年有工作专门主张用蜜罐对付 agent 内部人威胁，也有系统化综述把多智能体风险拆成交互接口、对手位置和系统级失效。

七、四条推论：Agent 经济体的要件#

把两个实验合起来看，一个能承载资本的 agent 系统需要四件东西，每件都可以挂价格：

要件这次实验里的证据真实世界的对应物
资本限额与风险预算60%→40% vs 85%→70%，上限没人重估风控额度、VaR、保证金
工具资本（脚手架）换作者：数天沉船 → 12 小时零损失交易基础设施与执行算法
验证与交叉检查跳过核对的几次，代价最高对账、四人复核、独立报价
声誉与职责分离破坏者专挑无人能反驳的岗位审计日志、权限分离、KYC

再往上一层，是经济学的问题。Anthropic 另外两组实验给了两条互补的证据：Project Deal（69 人、一周、186 笔成交）里，同一个坏折叠车，Opus 代理卖到 65 美元，Haiku 只卖到 38 美元，参与者却察觉不到自己吃亏；Project Swap（201 人、205 场市场）里，最终效率 0.55，最优是 0.89，而缺口的 85% 来自"没理解委托人想要什么"，不是交易技巧——同时"换更强的模型"比"换指令"更能改善结果。

三条合起来说的是同一件事：agent 质量的差距会以看不见的方式转移财富。而看不见的转移不会被市场自动纠正，因为受影响的一方没有反馈信号。

如果你是做投资或做基础设施的，我的判断是三条：

  1. 未来 12–24 个月，钱在"执行层"，不在"预测层"。 做市、清算、对账、合规检查、报价执行——这些是"给定结构找无效率"的一阶问题，agent 已经能盈利；而"预测下一步"仍然是抛硬币。
  2. 真正的收租位是"信用基础设施"。 Agent 身份注册、审计日志、声誉、担保、争议处理。市场越大，越需要有人为"这个 agent 是谁、出事了谁赔"定价。
  3. 模型版本正在变成一种 beta。 四个月三倍的斜率意味着：把模型当成可折旧资产来管理（升级节奏、回滚能力、按版本做归因），会直接体现在收益曲线上。

八、这个实验不能证明什么#

诚实边界必须写清楚，否则上面的推论会被滥用：

  • 模拟器无法对 agent 的行为作出反应，因此测不到"策略被市场反噬"的完整回路；合成压价单只是部分补丁（利润 −35%）。
  • EVE 的摩擦是 560 个基点，真实市场是 1–2 个基点；EVE 没有做空、杠杆、衍生品、保证金追缴。别把这里的夏普比率搬到真实资管。
  • agent 不能操纵市场，也没有面对过真正的对手方恶意（除了一次被指派的破坏）。
  • 破坏者是被 prompt 指派的，所以实验测的是"被要求背叛时能不能做到"，不是"会不会自发背叛"。
  • 样本是模型代际的横截面，不是长期演化；“四个月三倍"是这一段曲线的斜率，不是定律。

Project EVE 的用处在于它把"Agent 经济体"拆成了三张可以逐项计价的账单，执行一张、工具一张、信任一张。三个价格都还在往下走。
