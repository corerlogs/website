Open source: NetHandle, a high-performance network listener for Go

Posted by LB on Wed, Jan 2, 2019

NetHandle

A library for building high-performance TCP servers, standing on the shoulders of Go.

Repository: https://github.com/gitsrc/NetHandle

Features

  1. High throughput, low resource use.
  2. A very small API surface to learn.
  3. TCP, UDP and UNIX sockets.

Install

1go get -u github.com/gitsrc/NetHandle

Benchmarks

50 threads × 10,000 requests

50 threads × 20,000 requests

100 threads × 10,000 requests

The harness and the raw output are in the repository; the numbers above are from a single machine, so treat them as a relative comparison rather than a capacity claim.
