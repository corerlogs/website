NetHandle

A library for building high-performance TCP servers, standing on the shoulders of Go.

Repository: https://github.com/gitsrc/NetHandle

Features#

  1. High throughput, low resource use.
  2. A very small API surface to learn.
  3. TCP, UDP and UNIX sockets.

Install#

go get -u github.com/gitsrc/NetHandle
