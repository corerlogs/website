  6. 2026.11.05 逐节读 DSec：每天 300 万个沙箱，DeepSeek 把 agent 训练的底座做成了什么 把 31 页的 DSec 报告按节拆开读：先量负载（批量、稀疏、有状态、低复用），再讲三个机制（可组合层、内存回收、按需镜像），最后看评测里的 1.71× 与 45.2%→17.3% 到底证明了什么、没证明什么。 AI →
  7. 2026.11.05 Open Responses：把 N×M 套适配器换成一份契约，代价写在每个字段的 MUST 里 一份以 OpenAI Responses API 为基础、规定请求与响应格式的共享规范，能替掉一堆供应商适配器。真正值得读的不是字段名，而是条目状态机、语义事件、以及 allowed_tools、truncation、previous_response_id 这几个字段背后那句 MUST——它们把「谁能替你决定什么」写清楚了。 AI →
